登録された 2 次元点集合上で，点更新と矩形集約を行うセグメント木．

SegmentTree2D<M> として使う．M は可換モノイドとする．

  • SegmentTree2D<M>(points)：更新されうる点集合 points で初期化する．重複は取り除かれる．
  • apply(x, y, v)：点 $(x,y)$ にある値を M::op(current, v) で更新する．
  • set(x, y, v)：点 $(x,y)$ の値を v にする．
  • get(x, y)：点 $(x,y)$ の値を返す．
  • prod(xl, xr, yl, yr)：$xl\leq x<xr,\ yl\leq y<yr$ に含まれる登録点の値を集約する．
  • contains(x, y)：点 $(x,y)$ が登録済みかを返す．

apply, set, get の点は構築時に points に含まれている必要がある． 矩形内に登録点が存在しない場合，prod は M::e() を返す．

計算量

登録点数を $N$ とする．

  • 構築：$O(N\log N)$
  • apply, set, get：$O(\log^2 N)$
  • prod：$O(\log^2 N)$
  • 空間：$O(N\log N)$

仕組み

$x$ 座標方向にセグメント木を作り，各ノードにその区間に含まれる点の $y$ 座標でさらにセグメント木を持つ．

座標圧縮しているため，巨大な座標や疎な点集合でも扱える．
